# FenixTG - Telegram-бот для приема заявок

Автоматизированная система анкетирования и модерации заявок для закрытого сообщества.

## Функционал

### Для игроков:
- Заполнение базовой анкеты (3 вопроса)
- Выбор роли с дополнительными вопросами
- Получение инвайт-ссылки после одобрения

### Для админов:
- Управление ролями через команды `/add_role` и `/remove_role`
- Модерация заявок с inline-кнопками
- Анонимный диалог с игроками через режим "моста"

## Установка

1. **Клонирование и настройка:**
```bash
cd FenixTG
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows

pip install -r requirements.txt
```

2. **Конфигурация:**
```bash
cp .env.example .env
```

Отредактируйте `.env`:
```
BOT_TOKEN=your_bot_token_from_BotFather
ADMIN_GROUP_ID=-1001234567890  # ID группы админов
PLAYER_GROUP_ID=-1001234567890  # ID группы игроков
```

**Как узнать ID группы:**
1. Добавьте бота в группу
2. Напишите любое сообщение
3. Перейдите в браузере: `https://api.telegram.org/bot<YOUR_TOKEN>/getUpdates`
4. Найдите `chat.id` в ответе

3. **Запуск:**
```bash
cd bot
python main.py
```

## Команды администратора

### Управление ролями (только в админ-чате):

**Создать роль с вопросами:**
```
/add_role Строитель | Опыт в строительстве? | Примеры работ?
```

**Создать роль без вопросов:**
```
/add_role Наблюдатель | пусто
```

**Удалить роль:**
```
/remove_role Строитель
```

### Модерация заявок:

В админ-чате под каждой заявкой появляются кнопки:
- **✅ Принять** — отправить инвайт-ссылку игроку
- **❌ Отказать** — отклонить заявку
- **💬 Спросить** — начать диалог с игроком
- **📜 Посмотреть предыдущую анкету** — появляется, если у игрока есть отклоненные заявки

### Режим диалога:

После нажатия "Спросить":
1. Админу в ЛС приходит история анкеты
2. Все сообщения админа пересылаются игроку
3. Все ответы игрока пересылаются админу
4. Для выхода: отправьте `Backward` в ЛС боту

## Права бота

Бот должен быть администратором в:
- **Админ-группе** (для чтения команд)
- **Группе игроков** (право "Invite Users" для генерации ссылок)
